# Parts Ассистент — браузерное расширение (MV3)

Чат с ассистентом техподдержки WebCheckDB в контексте открытой страницы.

## Возможности
- 💬 Чат с базой знаний (тикеты/доки Parts.Intellect / Parts.Resource) — как на сайте
- 📄 **«Страница»** — подтягивает читабельный текст открытой вкладки (или выделенный
  мышкой фрагмент) в контекст LLM первым источником `[Страница 1]`
- 👁 **«Скриншот»** — снимок видимой области страницы уходит в vision-модель
  (облачный gemini; локальная Gemma — текстовая, картинки не видит)
- Лоадер «Ассистент думает...» — тот же ASCII-котик с дискошаром, что и в веб-чате

## Установка (Chrome / Edge / Яндекс.Браузер)
1. `chrome://extensions` → включить **Режим разработчика**
2. **Загрузить распакованное расширение** → выбрать папку `extension/`
3. Закрепить иконку (пазл → 📌), клик — откроется боковая панель

## Настройка
⚙ → адрес бэкенда (`http://sup5.tradesoft.corp:8000`, работает из корпоративной сети)
и **API-токен** (админка WebCheckDB → токены; скоуп `tickets`).

## Замечания
- На служебных страницах (`chrome://`, магазин) текст/скриншот взять нельзя
- История чата живёт на сервере по `session_id`, панель хранит сессию до перезагрузки
